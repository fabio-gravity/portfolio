Sobre esta Aplicação

1. Arquitetura MVT do Django

O Django segue o padrão arquitetural MVT (Model-View-Template):

  • Model — define a estrutura dos dados e interage com a base de dados via ORM
  • View — contém a lógica de negócio, recebe pedidos HTTP e retorna respostas
  • Template — ficheiro HTML com linguagem template Django para renderizar dados dinâmicos

Fluxo: Browser → URL → View → Model (BD) → Template → HTML → Browser

2. Modelação

O diagrama entidade-relação foi desenhado à mão antes da implementação. O projeto contém 9 entidades: Tecnologia, Competência, Formação, Docente, Licenciatura, Unidade Curricular, TFC, Projeto e Making Of.

4. Estrutura de Navegação

A aplicação está organizada em duas apps:

  • portfolio — páginas do portfólio pessoal (tecnologias, projetos, competências, formações, UCs, TFCs, making of)
  • escola — exercício prático (cursos, professores, alunos)

5. Repositório GitHub

Ver repositório no GitHub

O GitHub permite controlo de versões, colaboração e histórico de alterações. Cada funcionalidade é submetida com um commit descritivo, facilitando o rastreio de erros e a documentação do progresso.

6. Making Of

O Making Of documenta todo o processo de desenvolvimento: decisões de modelação, erros encontrados e corrigidos, uso de IA, e evolução dos modelos.
